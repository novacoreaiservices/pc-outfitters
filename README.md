# PC Outfitters

Public site for PC Outfitters, a Windsor, Ontario computer repair and custom-build shop.

Live: [https://pcoutfitters.ca](https://pcoutfitters.ca)

## Stack

TanStack Start, React, Vite, Tailwind CSS v4. Hosted on Netlify.

## Develop

```bash
npm install
npm run dev
```

The dev server listens on port 8080.
